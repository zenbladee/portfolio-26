Experiments

This page is for homework experiments.

Template

A template is a pre-designed layout or structure that can be used as a starting point for creating new content.

audio

The audio element is used to embed sound content in the document.

video

The video element is used to embed video content in the document.

canvas

The canvas element is used to draw graphics on the fly via scripting (usually JavaScript).

Your browser does not support the canvas element.

source

The source element is used to specify multiple media resources for media elements like audio and video.

svg

The svg element is used to define vector-based graphics for the Web. SVG stands for Scalable Vector Graphics.

iframe

The iframe element is used to embed another HTML page within the current page.
